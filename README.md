# toıdym

Flutter жобасы. Астанадағы кафе мен наубайхана бокстарын көруге, брондауға және орнынан алып кетуге арналған қазақша және орысша демо.

## Web нұсқасын іске қосу

Chrome-да жылдамдығын тексеру үшін release режимін қолданыңыз.

```powershell
flutter pub get
flutter run -d chrome --release
```

Осы компьютерде `flutter` командасы PATH ішінен табылмаса, жоба қалтасында мына командаларды орындаңыз.

```powershell
$flutter = Join-Path $env:LOCALAPPDATA 'toidym-dev/flutter/bin/flutter.bat'
& $flutter pub get
& $flutter run -d chrome --release
```

Жоба Flutter 3.47.9 нұсқасымен тексерілді. Android телефоны немесе эмуляторы үшін `flutter devices`, содан кейін `flutter run -d <device-id>` орындаңыз. iOS-ты құрастыру үшін macOS және Xcode қажет.

```powershell
dart analyze
flutter test --concurrency=1
flutter build web --no-web-resources-cdn
```

Дайын `build/web` жинағын осы қалтадан жергілікті сервермен ашуға болады.

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory build/web
```

[Жергілікті Web нұсқасы](http://127.0.0.1:8765/)

## Демо жолы

1. «Бастау» түймесін басып, Есіл ауданын таңдаңыз. Каталог пен картаға қонақ ретінде кіруге болады.
2. «Таңғы нан» боксын ашып, брондаңыз. Кез келген сынақ телефон нөмірін және **4821** демо кіру кодын енгізіңіз.
3. Броньды растаңыз. Тапсырыстағы QR мен төрт таңбалы беру кодын ашыңыз.
4. Профильдегі «Кәсіпорын режимі» арқылы наубайхана демосын ашыңыз. «Беру» бөлімінде тапсырыстың төрт таңбалы кодын енгізіп, беруді растаңыз.
5. Сатып алушының өткен тапсырыстарынан «Ас болсын!» экранын ашып, баға беріңіз.

## Іске асыру

- Бокс каталогы, іздеу, санат пен халал сүзгілері, OpenStreetMap картасы, мекеме карточкасы және таңдаулылар.
- Бронь, орнында төлеу, QR және беру коды, тапсырыс тарихы, үнем есебі және жергілікті шағым.
- Мекеменің демо өтінімі, боксты жариялау, қалдықты өзгерту, тапсырысты беру және табыс есебі.
- Бастапқы `design.svg` экспортынан логотип бөлек SVG ретінде алынды, ал тағам суреттері мен сәлемдесу фоны WebP-ке ықшамдалды. Экрандар интерактивті Flutter виджеттерінен тұрады.

Каталогта үлгі деректер қолданылады. Өзгерістер құрылғыда немесе браузерде сақталады. Кіру коды мен мекемені мақұлдау демоға арналған. Нақты SMS, төлем, серверлік синхрондау, push және төлем аударымдары үшін тиісті интеграциялар қажет. Аудан қолмен таңдалады, ал жаңа мекеменің карта нүктесі демода аудан ортасына қойылады. Карта мен сыртқы бағытты ашу интернетті қажет етеді.
